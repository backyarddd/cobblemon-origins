# Cobblemon Origins

Official repository and issue tracker for **[Cobblemon Origins: Road to Champion](https://www.curseforge.com/minecraft/modpacks/cobblemon-origins-road-to-champion)**, a Cobblemon modpack for Minecraft 1.21.1 (Fabric).

- **Play:** install the pack from CurseForge. The official server is `play.cobbleorigins.net`.
- **Bugs:** open an [issue](../../issues/new/choose) with your pack version and your `latest.log` or crash report.
- **Help and chat:** [Discord](https://discord.gg/tEtQvqXjf8).

## What is in this repository

The pack's configuration exactly as it ships, so changes can be reviewed and tracked:

- `config/`: mod configs, the questbook (FTB Quests), menus (FancyMenu) and the pack's own datapacks under `config/paxi/datapacks/`:
  - **Cobblemon Origins Fixes:** spawn fixes, recipes, advancements and compatibility tweaks
  - **Cobblemon Origins Shrines:** the legendary shrines
  - **Cobblemon Loot Plus:** extra Pokémon loot
- `defaultconfigs/`: per-world defaults copied into new worlds
- `CHANGELOG.md`: what changed in each release

Mod jars are not included: they belong to their authors and are downloaded by CurseForge. Some pack files that are copies
of other projects' assets or data (recoloured Cobblemon textures, restored Cobblemon / Mega Showdown / Complete Cobblemon
Collection species and spawn data) ship in the pack but are left out of this repository.
